# Казна клана

Учёт обозов на постройку столицы клана в Total Battle: дерево, камень и железо — по 50 млн каждого.

Всё приложение — один файл `index.html`, работает без сервера: просто откройте его в браузере.

## Что умеет

- **Обозы** — журнал «кто, когда, сколько прислал», прогресс по каждому ресурсу до цели, топ вкладчиков и список тех, кто не присылал (за 7/14 дней или вообще ни разу).
- **Участники** — справочник клана с быстрым массовым добавлением (вставьте список ников целиком, нумерация отбрасывается).
- **Могущество** — замеры могущества участников по датам, интерактивный график роста и сводка прироста.
- **Данные** — цели по ресурсам, экспорт/импорт JSON для резервных копий, пример данных для знакомства.

Количества можно вводить сокращённо: `500к`, `1.5м`, `2кк`, `1.2б`.

## Хранение данных

Данные хранятся в localStorage браузера, в котором открыта страница. Периодически делайте выгрузку во вкладке «Данные» и сохраняйте её в надёжном месте.
