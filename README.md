# Казна клана

Учёт обозов на постройку столицы клана в Total Battle: дерево, камень и железо — по 50 млн каждого.

## Архитектура

- **`data.json` — единственный источник правды.** Все участники, обозы и замеры могущества лежат в этом файле в репозитории.
- **`index.html` — всё приложение одним файлом.** При открытии оно читает `data.json` через GitHub API и каждое изменение само коммитит обратно (нужен fine-grained токен с правом Contents: Read and write только на этот репозиторий — вводится один раз на устройство во вкладке «Данные»).
- **localStorage — только офлайн-кэш.** При расхождении локальные изменения сливаются с данными из git: участники сопоставляются сначала по внутреннему id (переименование ника не плодит дублей), затем по нику; уровень берётся больший, чтобы отставшее устройство не откатило свежие данные; удалённые записи не воскресают (тумбстоуны в `data.json → gone`).
- Вся работа идёт в ветке `main`; она же публикуется на GitHub Pages: https://2alen.github.io/clan-game-utils/

## Что умеет

- **Обозы** — журнал «кто, когда, сколько прислал», прогресс по каждому ресурсу, топ вкладчиков, список молчунов и генератор сообщения для кланового чата (английский, без цифр по людям).
- **Участники** — справочник клана со званиями и уровнями; массовая вставка ростера в формате `ник | уровень | могущество | звание`.
- **Могущество** — замеры по датам, интерактивный график роста, сводка прироста.
- **Данные** — настройка токена, цели по ресурсам, выгрузка/импорт JSON.

Количества вводятся сокращённо: `500к`, `1.5м`, `2кк`, `1.2б`.
