Синхронизация с GitHub

Все данные хранятся в файле data.json в репозитории 2alen/clan-game-utils — это единый источник правды для всех устройств. Смотреть данные можно и так, а чтобы записывать обозы, нужен ваш токен GitHub: без него записи останутся только в этом браузере. Токен сохраняется только в этом браузере и в репозиторий не попадает.

Как сделать токен (один раз, ~2 минуты)
  1. Откройте github.com/settings/personal-access-tokens → Generate new token.
  2. Repository access → Only select repositories → выберите clan-game-utils.
  3. Permissions → Repository permissions → Contents → Read and write. Больше ничего.
  4. Generate token, скопируйте строку вида github_pat_… и вставьте её сюда.
